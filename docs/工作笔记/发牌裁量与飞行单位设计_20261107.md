## A. 发牌裁量：没空位只发军队

### 判据（唯一一处）

`buildingPlacementIssue(side,col,row)`：己方半场 + 3×3 不越界 + 三列不压黄区 +
不与任何楼重叠。`placementProblem`（落牌拒绝）、`buildingRoom`（还有没有空位）、
发牌过滤**三件事共用它**，不另算一套账。

### 动作

| 动作 | 没空位时 |
| --- | --- |
| `draw()` 补牌 | 卡池过滤掉建筑卡；**跳过后勤保底与建筑保底**（否则又塞回来） |
| `reroll()` 刷新 | 同上，不再强制塞 `house`/`mill` |
| 手牌里已有建筑卡 | 建筑落地把最后一处空位占掉时，立刻换成军队卡（槽位/冷却不动） |
| HUD | 手牌区小标「场地已满 · 只发军队」，读同一个 `buildingRoom` |

有空位后自动恢复全池；蓝红双方同一条规则；刷新仍花 5 金，裁量只决定发什么。

## D. 三架 3D 模型（简化口径）

| 部件 | 热气球（自建） | 空气螺旋机（HTML1） | 扑翼轰炸机（HTML2） |
| --- | --- | --- | --- |
| 主体 | Sphere 12×8 拉长（阵营花色）+ 木吊篮 | Cone 10 段尖朝下 + 平台 | 龙骨 Cylinder + Torus 开放座舱 |
| 翼/帆 | 4 根吊绳 + 顶旗 | helix 2×48 / 1.6 圈（花色帆布）+ 6 根径向骨 | 2 片三角翼 BufferGeometry + 燕尾 2 片 |
| 动件 | 球囊轻摆 | 螺旋转子 `rotor.rotation.y` | 前螺旋桨 `rotor.rotation.z` + 机翼颤动 + 脚踏轮 |
| 骨架 | — | 主轴 + 4 根纵条 | 翼肋 3 根/侧 + 支柱 |
| 缩放 | ~0.85 | ~0.8 | ~0.22（原机翼展 9 格） |

- 全部缩到 ~1.6 格高；球囊/帆布用**玩家花色主色**（接上花色系统）；
- 受击闪白用「材质往白 lerp」（同建筑泛白那套），像素小人那套不适用 3D。

## E. 扑翼轰炸机：一次性冲刺（独立逻辑）

- 落牌后**不索敌、不普通攻击**，每帧朝敌方大本营方向直飞（蓝 +x / 红 -x）；
- 「下方有敌方军队」= 半径 2.5 格内有敌对**单位**（不算建筑）→ 投弹：
  以该点为中心 1.6 格溅射、22 伤，视觉走现有 `ammo:'cannon'` 黑球 + 爆炸火星；
  投弹间隔 1.4 秒（`bombIn` 计时），不因投弹减速；
- **飞出地图（x < -1 或 > cols+1）直接消失**，不留尸体、不算被拆；
- **在地图内被击毁 → 解体**（碎块 + 火，见 F 节）；视图靠 `world.leftField` 集合
  区分「离场消失」和「被击毁」，别把离场也播成解体；
- 它是一次性消耗单位：飞出后容器（人口/面包）随单位移除自动释放。

## F. 摧毁画面（用户第 1/2 条）

| 对象 | 表现 | 时长 |
| --- | --- | --- |
| **小人 / 锥体兜底** | **倒地不动**：`play('die', time, false)` 停在最后一帧，不再逐帧切动画；影子变淡，尸体留在原地 | 2.6 秒后渐隐移除 |
| **弩车 / 炮车 / 飞行单位被击毁** | **解体**：整组子件散开下落（随机速度/旋转）+ 火星 + 烟/火光（`fx.spark` 连放 1.5 秒模拟火焰） | 2.6 秒后移除 |
| 轰炸机飞出界 | 直接移除，无特效 | — |

- 尸体/残骸存进视图自己的 `corpses` 数组，每帧 `stepCorpses(dt)` 推进，别碰逻辑层；
- 死亡音效仍播一次；死亡烟 `fx.death` 保留给小人，车/飞机改用爆炸火星 + 持续火光。

## 验收口径

1. `npm run check` 全绿 + 新锁：没空位 draw/reroll 不出建筑卡、有空位恢复、
   `buildingRoom` 与 `playCard` 判据一致、新卡价/人数、飞行越障、轰炸机
   投弹/离场/被击毁三条路径；
2. 实机：铺满半场 → 手牌只剩军队 + HUD 小标；拆一栋 → 建筑卡回来；
   三架飞行器外形可辨、悬浮、转子会转；轰炸机沿直线投弹后飞出界；
   小兵倒地停留、弩车解体冒火；
3. 24 局探针：拆楼/胜平读数不退化（新卡进池改变抽卡分布，记录下来）；
4. 桌面 HTML zip / 安卓 APK 重出并装到手机。
