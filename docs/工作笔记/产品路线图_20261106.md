## ⏳ 阶段 1：单人 PVE（像植物大战僵尸的那一半）

不做联网，可以单独上 TapTap，**3–5 天**。

### 现成能复用的（不用重写）

| 已有的 | 在 PVE 里干什么 |
| --- | --- |
| 手牌 + 金币 + 建筑产能 + 施工时长 | 就是"种植物 / 布防"的那一层 |
| 兵线推进与寻敌 | 反过来用：红方按波次表出怪 |
| 后勤名额 / 人口 / 面包 | 关卡里的资源节奏，全部现成 |
| 围墙与看台 | 换成"防线"的视觉框，方向不用改 |
| 粒子 / 音效 / 震屏 | 直接复用 |

### 要补的三样

1. **关卡数据**（`src/arena/pve/waves.ts`）：时间点 + 敌人组合 + 出生点 + 波次间隔；
2. **单线行进 AI**：不寻敌，只沿一条路往前走 + 打挡在前面的建筑（现有 `nearestHostile` 要能切模式）；
3. **胜负判定**：守住 N 波 / 大本营血量归零，替换现在的 3 分钟比分。

### 还没定的问题（等用户拍板）

- 出怪从**右边一条线**来，还是像 PVZ 那样**分多路**？多路要改地图分道，工作量翻倍。
- 玩家这边还有没有"对面大本营"？PVE 大概率不需要——那结算 UI 要换。
- 关卡之间的**成长**（卡牌解锁 / 升级）做不做？TapTap 审核把"无存档、无成长"列为驳回点，这条建议做。

## ⏳ 阶段 2：多人 PVE / 联机

玩家 2 人合作守同一波怪。必须先有联机。

### 联机方案（已评估，见 `上架与联机评估_20261105.md`）

| 检查项 | 读数 |
| --- | --- |
| `ArenaWorld` 里的 `Math.random` | **0 处**（全走 seeded rng） |
| 主循环 | 固定步长 20Hz，渲染与逻辑分离 |
| 逻辑层是否依赖 three | **不依赖**，服务器可以直接跑 |

**推荐状态同步**（服务器跑一份 `ArenaWorld`，每 100ms 广播快照），不是帧同步：
不用赌 JS 引擎之间 `Math.hypot` / `atan2` 的 1 ulp 差异，也不用做客户端预测和回滚。

最小可玩（房间 + 匹配码 + 快照 + 断线）**3–5 天**；帧同步 7–10 天且更难调。

### 多人 PVE 额外要补的

- 两个玩家共用一张场地，但**各发各的手牌**（`hands` 已经是按 side 分开的，加第三个 slot 即可）；
- 波次怪对两个玩家都算敌对（现在 `side` 只有 blue/red，需要引入 `neutral` / `pve`）；
- 结算改成"队伍守住 N 波"。

## ⏳ 阶段 3：上架 TapTap

### 走哪条路

TapTap 有四种形态，**我们是纯 Vite + Three.js 的 Web 应用，走「H5 游戏」**（部署在平台域名下）。
不要照着「Tap 小游戏（WebGL）」的文档去接 Unity/Cocos 打包工具——官方原话："读错档是返工最常见的原因"。

### 硬性指标

| 要求 | 我们现在 |
| --- | --- |
| 首包 ≤ 60MB | `dist` 约 **0.7MB** ✅ |
| 接 TapTap 登录 | ⏳ 未接 |
| 无内购免版号，但要**小游戏前置备案** | ⏳ 未做 |
| 9:16 竖版实机截图 + 图标 | ⏳ 未做（现有全是横版） |
| 审核 1–3 天 | — |

### ⚠️ 一条决定顺序的规矩

官方 FAQ：**"单机改联网、无广告改有广告"属于较大变动，要按变化后的要求重新处理资质。**

所以：

> **如果多人 PVE 在计划里，联机就得和备案在同一版做完。**
> "先上单机试试水，以后再加联机" = 备案重做一遍。

## 依赖顺序（一张图）

```
竞技场 1v1（现在，已能玩）
   │
   ├─→ 音效 / 竖屏适配 ──────────────┐
   │                                │
   ├─→ 单人 PVE（不碰联机，可独立上）─┤
   │                                ├─→ 商店素材 / 备案 / 提审
   └─→ 联机（状态同步）              │
          └─→ 多人 PVE ─────────────┘   ← 联机与备案必须同一版
```

## 还没拍板的事

1. PVE 是**单线**还是**多路**；
2. PVE 要不要卡牌解锁 / 成长（影响 TapTap 过审）；
3. 联机是这次上架就带，还是先单机、接受以后重新备案；
4. 竖屏要不要作为主视角（现在相机 fit 是按横版算的，竖屏背景偏黑）。
