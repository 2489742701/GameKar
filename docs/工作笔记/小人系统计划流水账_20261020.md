### 2. 根据的读数（都是今天现量，不是从文档抄的）

- 生成器不是程序化几何，**全程没有三角函数**：`grep -E "Math\.(sin|cos|atan|hypot|pow)" app.js` → **0 命中**
  （第一种姿势 `grep -c` 返 0 会以退出码 1 掐断命令串，所以换 `grep -n … | wc -l` 又数了一遍，同样 0）。
- 管线核心就一个函数：`app.js:729 Canvas.blitAll(ctx, frame, animName)` = 三次 `drawImage` + `app.js:750 recolor()`。
  偏移公式（`app.js:732-745`）：base 用 `-getAnimX0(anim,frame)*w` 横向取帧、`-State.base*h` 纵向选体型；
  head/face 用 `-index*w` 选件、`Conf.getOy(part, anim, frame)` 做逐帧上下浮动。
- 一格 **16×24**（`app.js:713-714`、`conf.json w:16 h:24 version:3`）。
- 资产实测尺寸：`base.png 11248×24 → 703 帧 × 1 个体型`；`heads.png 5328×24 → 333 个头`；
  `faces.png 1648×24 → 103 张脸`。`Parts.els.{base,head,face}.max` 运行时读到 **0 / 332 / 102** ✓ 对得上。
  ⇒ 这个移植包**只有一个体型骨架**（代码里被注释掉的体型上限 15/32/53/77 是原版 human/animal/monster 的分段行，本包没带）。
- 我要用的 5 个动画，列号与循环长度（`app.js:83-87` + `app.js:220-224`）：
  `base_stand` 起 0 长 1 ｜ `base_idle` 起 2 长 4 ｜ `base_run` 起 7 长 4 ｜ `base_hurt` 起 12 长 4 ｜ `base_die` 起 17 长 4。
  注意 idle 占 2–6 但 modF 是 `%4`，**第 6 列是不用的余量**，别按间隙长度当帧数。
- 调色板语义（直接读的 `app.js:772-825`）：源色 `skin 绿→Pal.all.body`、`eyes 红→Pal.all.eyes`、
  `suit 蓝→Pal.all.suit`、`item 品红→Pal.all.item`、`more 青→Pal.all.more`；`outline 黄→conf.outlineColor`；
  四个 `*2` 阴影变体 = 同色 × `shadowMod`（conf 里四个都是 **0.5**）再 `parseInt`。
- **UI 变量名是反的**：`app.js:617-618` `palBody = Pal("eyes")`、`palEyes = Pal("body")`。
  我做了实验定性：把 `Pal.all.body` 改成纯红，皮肤色 `238,181,81` **消失**、眼睛蓝**还在** ⇒ `conf.pals.body` = 皮肤色 ✓。
  另：`conf.saved_state` 里的 `palBodyActive=#eeb551` 与运行时 `Pal.all.body` 现值 `#d9a6a6` **不一致**，
  ⇒ `saved_state` 只能当"上次谁选了哪件"的存档，**不能当调色板语义的依据**。
- 一帧实测 14 种输出色；其中 `?`（不匹配任何魔术色的像素）4–14 个 —— 这些**原样保留**，不参与换色。
- **没有 facing 参数**：全代码只有一处 `scale(-1,1)` 的 CSS 镜像（`app.js:3972`，气泡彩蛋）。
  ⇒ 素材都是侧视；左右只能镜像，做不出 8 向。
- **不可播种**：`Math.random()` 满天飞（`app.js:80,1629,4570…`），没有 seed 概念。
  ⇒ 我自己用项目里现成的 `Random`（`src/engine/math/Random.ts`）驱动 index 与颜色，**不造第二个随机数发生器**。
- 经济那侧今天已锁死的口径（要直接复用，不许改）：`每秒趟数 = speed ÷ max(1, 2×格数)`、`每趟 perTrip`；
  矿井 speed 1.2 / perTrip 2，精炼厂 3.2 / 2.2；实测 3 格外矿井 = 0.4/s、精炼厂 = 1.173/s。
- 授权实读：`LICENSE` 头部是 **GNU AFFERO GENERAL PUBLIC LICENSE v3**；
  `README.md`/`manifest.toml` 只说这是 kingbell.itch.io/pixel-sprite-mixer 的 webxdc 移植，
  `source_code_url = github.com/ArcaneCircle/pixeldudes-maker`。**素材（PNG/conf）自身的授权条款仓库里没有**。

### 3. 会动到哪一面

- **只有时间**：新增模块在启动时烘几张纹理（估算：每个样式 13 帧 × 16×24，一次 recolor 384 像素，
  10 个样式约 5 万次像素操作，应 <15ms；跑完实测贴在回填里）。
- **会改答案面：不动。** 经济/抽卡/人口/放置的任何一个读数都不改；小人只做视觉与时间映射。
  唯一"新增压数"是 draw call（每个小人一块 quad + 一份材质）——这是性能面，不是答案面，回填里量。
- **崩溃后丢多少**：只丢视觉。小人与纹理都可由 (seed + 建筑) 重建，不写盘、不进存档，删掉整个 `dudes/` 游戏照样跑。

### 4. 怎么证明没改答案

- 跑法：改动前 `npx vitest run` 记一次（现在 **94 条全绿**），改动后必须仍 **94 条全绿且不删不改任何一条断言**；
  新增的锁只加在 `tests/dudes.test.ts` 里。
- 口径同一性用一条**等值锁**证明，而不是靠"看起来对"：
  `crystalPerTrip ÷ tripSeconds(楼, 矿) == world.yieldOf(楼).crystal`（同 seed 同布局），
  也就是"画面里的脚程"和"账上的脚程"必须是同一个数派出来的两面；把 `2×格数` 写成 `1×格数` 这条必须打红。
- 每条新锁都先想好怎么打红（写不出打红方式的，就不写那条锁）：
  - recolor 锁：把阴影分支从 `×0.5` 改成 `×1` → 红；把 `skin2` 分支删掉 → 红；把容差 ±1 放宽到 ±60 → 红
    （因为 `eyes 红(255,0,0)` 与 `item 品红(255,0,255)` 只差一个通道，容差一大就互相吞）。
  - 风格确定性锁：`new Random(seed)` 两次 `randomStyle` 必须逐字段相等；把 head 上界写死成 163（原代码那个数）
    而不是读到的 332 → 越界断言红。
  - 帧表锁：`startCol + frames ≤ 703` 且 5 个动画列号/长度等于上面那 5 个读数；把 run 起始改成 6 → 红。
  - 资产锁：`conf.w/h` 与 PNG 实际宽高、`heads/16-1` 与 `maxima.head` 互相对得上；把 w 改成 17 → 红。

### 5. 风险与代价

1. **授权未定（最该他拍板的一条）**：代码我不搬（AGPL），自己重写；但 `base/heads/faces.png + conf.json`
   是别人的**美术素材**，仓库里没有素材授权说明。我按"4 个文件可整体替换"的形态摆好，
   并且写 `CREDITS.md` 记来源与待确认；真要对外发布前他得确认 itch 页面条款。
2. **只有一个体型**：本包 base 只有 1 行，所有小人同骨架，靠 333 头 × 103 脸 × 5 组色区分。
   想要 human/animal/monster 多体型，得让他从 itch.io 拿完整数据包，接口已按 rows 留好（`State.base`）。
3. **侧视素材 + 50° 俯视相机**：小人是一张竖起来的卡片。可能好看（正是 2.5D 那味），也可能像贴膏药。
   我这边**看不到画面**（内嵌浏览器面板不可见），所以高度/是否站直/是否压暗都做成一个可调数值，请他眼睛定。
4. draw call 上升：先按"每栋楼最多 3 个小人"限死，量出来不划算再合并图集/实例化。
5. 纹理是启动时烘的：样式数若爆炸（每次抽卡都换装）会掉帧；第一版**每种建筑一个固定样式**，不随楼数增长。

**中途被实验推翻的一个设计：左右翻面**

原计划在 `DudeSprite` 上做 `setFlipped`（往左走就镜像）。我量了剪影左右对称度：
idle 0.969、base_run 0.964/0.943、run_one 0.964、run_ninja 0.917 ⇒ **素材是正面的**，
镜像一张正脸不会变成"转身"，只会像被人水平翻过。于是删掉 `setFlipped` 与相关字段，
小人只绕 Y 轴转到正对相机（实测 `rotationY = 0.785 rad = 45°`）。
连带把 `CameraRig.groundBasis` 从"为翻面而公开"改回 private。
