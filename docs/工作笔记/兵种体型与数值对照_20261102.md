# 兵种体型与数值对照（2026-11-02）

用户："有的军队太大，有的军队太小。比如说我们新造的那个手推炮，可能就较小，可以把它们放在一起对比一下情况，
然后数值也可以一起看一下。"

这一份只做**测量与对照**，没有改任何数值或模型 —— 结论和建议在最后，等拍。

## ① 身高是量出来的，不是估的

方法：`tools/unit_lineup.js` 在真页面里排好一排单位，遍历每个渲染对象的包围盒 8 个角点
（过世界矩阵，所以旋转过的炮管不会被当成竖直件），取脚到顶的高度。
跑法：`node tools/arena_shot.mjs "<url>" 3 out.png @tools/unit_lineup.js`

两条直接读数：

1. **攻城车是"人比炮高"**：火炮的车板贴地（0.52），炮管中心 0.86；
   旁边的推车小人是 1.6 格 —— 一辆 16 金的攻城器械，看起来像"两个人推着一口箱子"。
2. **兽人和骑士一样高**：兽人 80 血 / 15 攻 / 3 防，骑士 60 血 / 12 攻 / 5 防。
   数值上兽人是"更肉的近战"，屏幕上却和骑士同一个剪影。

## ⑤ 建议（都没做，等拍）

按"改动小、收益直接"排序：

1. **移动火炮放大车体**（只动模型，不动数值）：床 1.55×1.0 → 2.0×1.2，轮 0.32 → 0.42，
   炮管从 0.86 抬到 1.15、直径 0.24 → 0.30。目标：**炮管顶 ≥ 1.35 格**，让它压过推车人，
   读起来才是"炮"不是"箱子"。顺带把 16 金降到 14（或血 90 → 120），把性价比从垫底拉回中游。
2. **兽人抬到 1.65 格**（`heightTiles`），和骑士的 1.45 拉开 —— 血多 33% 就该看得出来。
3. **机器巨人先不动，但要知道它在哪**：每金 EHP 是第二名的 1.7 倍。真要调，把血 300 → 240
   （每金 EHP 降到 45，仍是第一），或者把价 16 → 18。
4. （可选，优先级最低）弓箭手 1.35 / 法师 1.50 / 牧师 1.40，让"谁脆谁远"在剪影上也成立。
