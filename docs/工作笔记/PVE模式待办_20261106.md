## 3. 红线（写下来防顺手）

- **不改 1v1 数值与判据**：金币 2 秒/格、建筑协调经济、拆楼判胜负、加时积分、
  蓝红对称性——PVE 要改就写自己的数据，不动 `config.ts` 的对战常量；
- **不用加钱/双倍金解决节奏慢**（这是刻意设计）；
- **建筑没有寿命**（不会自己掉血/定时消失）；
- **规则与文案同表**：波次/结算文案别在 UI 里重算一遍；
- 别为了"引擎化"在这轮顺手大重构（见 `分发与引擎路线_20261106.md`：先阶段 A，
  等联机立项时再做平台接口）。
