用户："现在建造科技有前置要求：想要造军队，默认只能造一个军队，就是**民兵集结**，
由 6 个小小单位组成（4 近战 + 2 弓箭手），攻击/防御低、人多、价格便宜。
**必须建造军营才能解锁更多军队**。**想要建造空中单位，需要齿轮工厂**。

## A. 科技前置：一张表管全部

| 想造什么 | 前置 | 判据 |
| --- | --- | --- |
| **民兵集结**（唯一默认军队） | 无 | 永远在卡池 |
| 其它**地面军队**（含弩车/火炮） | **兵营** | 己方有 ≥1 座**完工**的兵营（`build>=1 && hp>0`） |
| **三架飞行器**（热气球 / 空气螺旋机 / 扑翼轰炸机） | **齿轮工厂** | 己方有 ≥1 座**完工**的齿轮工厂 |
| 建筑卡 | 无 | 但受「场地有没有对应尺寸空位」裁量（P-056 的判据） |

- **施工中不算解锁**（项目红线：施工中的楼不干活）；建筑被拆 → 立刻重新上锁，
  手牌里不满足前置的卡当场换成允许卡（只换卡面，槽位/冷却不动）；
- 蓝红双方同一条规则（AI 也必须先盖兵营）；
- 解锁是**发牌层过滤**，不是「卡变灰」：池子外根本抽不到，玩家不会被一堆
  点不动的卡占手牌；
- HUD 小标按状态给提示：「需要军营解锁军队」/「需要齿轮工厂解锁空军」/
  「场地已满 · 只发军队」（优先级：场地 > 兵营 > 空军，按解锁顺序）。

## B. 民兵集结（默认军队卡）

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 价格 | **5 金** | 最便宜的卡，开局 8 金就能出 |
| 编成 | 4 民兵 + 2 弓箭手 = **6 人** | 用户指定「4 近战 2 弓箭手」 |
| 民兵数值 | hp22 / 攻5 / 防0 / 射1.2 / 速1.5 / 间1.1 | 明确"攻防低"，靠人数 |
| 弓箭手 | 沿用现有 archer（hp26/攻7/射4.2） | 复用，不另造数值 |
| **容器口径** ⚠️ | 6 人口 + **3 面包**（每人 0.5 面包） | 基础容器是 6 人口 / 3 面包，6 人×1 面包会**一张卡都放不下**；民兵自带干粮、半份口粮，正好压满基础容器，也保留"先盖民居/磨坊"的主线 |

- 实现：`ArenaCard.breadPerMan?: number`（默认 1）、`ArenaUnit.breadCost?: number`；
  `supplyOf` 按单位累加 `breadCost`，`supplyBlocked`/`canPlay` 按卡算，
  卡面两行需求也按「实际面包数」画（不是按人头 ×6 骗人）；
- 卡池新增第 24 张卡；民兵是**唯一**无前置军队卡。

## C. 齿轮工厂（4×3，复古 + 大齿轮）

### 占地与数值

| 项 | 值 |
| --- | --- |
| 占地 | **4 列 × 3 行**（第一栋非 3×3 建筑） |
| 血量 | 700（比普通楼厚一点，科技建筑值得拆） |
| 价格 | **16 金**（与炮塔同档，解锁空军要有代价） |
| 后勤 | **不需要民居**（被动科技，不开火不产兵；`needsStaffing` 不加它） |
| 人口 | 占 2（所有建筑统一），同样吃「给军队留 2 格」的槽位制衡 |

### 模型（复古工厂，稍微大一点）

- 主体：砖红/石灰色**厂房**（方墙 + 木梁 + 双坡顶），左侧一根**烟囱**（圆柱 + 顶箍），
  正面大门 + 两扇小窗；底部石台；
- **一个大齿轮竖在前墙外侧**（面朝镜头 z 方向）：深铁色圆盘（cyl 转 90°）
  + **12 个方齿** + 4 根辐条 + 金色轴心；
- 齿轮用现有 `spin` 节点机制（`kit.ts` 的 `SPINNERS`）：圆盘/齿/辐条都带同一个
  `pivot` 与 `speed:0.8`，`syncParts` 每帧按绝对角度转 → 整轮同步「转转转」；
- 第二个小齿轮咬合在旁边（反向转：`speed:-1.2`），机械感更足（⚠️ 若齿数看着乱，实机再调）；
- 缩放 `BUILDING_SCALE × 1.18`（4×3 本来更宽，模型也明显比 3×3 大一圈）；
- 旗位：屋顶靠右，阵营花色旗（沿用花色系统）；
- 卡面图标：齿轮剪影。

### 4×3 牵动的判据（全部参数化，不写死 3）

- `buildingPlacementIssue(side,col,row,cols,rows)`、`buildingRoom`/逐卡空位过滤、
  落牌 `placementProblem`、拖拽影子（4×3 的长方形占位 + 同一模型影子）、
  `place()`/`cellFree()` 的 spec 都按 `BUILDING_SPECS[kind]` 读；
- 黄区检查遍历 **4 列**（4×3 更容易压到黄区，判据不能只查 3 列）；
- `ARENA_MODELS` / `ARENA_FLAGS` / `labelOf` / `cardIcons` 都要注册新楼。

## D. 待用户看完实机再拍的点

1. 民兵「每人 0.5 面包」是容器口径的折中；也可以改成「民兵完全不吃面包」，
   但那会冲垮「盖磨坊」这条主线，我不建议；
2. 齿轮工厂是否要「生产」点什么（现在只是**被动解锁**科技 + 装饰齿轮）；
3. AI 是否主动把工厂列进建造愿望（本轮**不主动**，手牌里抽到才会盖，
   避免 24 局平衡被前置系统大幅改写）；
4. 4×3 在竖屏窄场地会不会显得挤（实机看）。

- `npm run check` **497 全绿**（+9 条：民兵/容器 2、科技前置 4、4×3 判据 3）；
