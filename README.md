# GAMEKAR

抽卡驱动的 2.5D 即时战略。建筑、经济、人口**全部**来自抽卡：盖楼要抽、加产出要抽、涨人口上限也要抽，
抽到的建筑卡就是一张"可以盖一次"的建造许可。防守靠塔与兵，进攻按**回合**来。

## 跑起来

```bash
npm install
npm run dev          # http://localhost:5173
npm run check        # 类型检查 + 225 条回归
npm run build        # 产物在 dist/，three 单独分包
```

开发期可以在控制台直接敲：

```js
game.pull(10)                 // 十连，走完整结算
game.build('farm')            // 进入田庄的放置模式
game.place('mine', {col:20,row:18})   // 跳过交互直接落位
game.world.resources          // 金币 / 晶钻 / 面包
game.upgrade(towerId)         // 升级一座塔（不扣许可）
game.stowFlag(barracks)       // 收集合旗 → game.armFlag() → game.dropFlag(cell)
game.prefs.themeId                    // 玩家自己调的界面材质（可分享的码）
game.setDifficulty('easy')    // 换难度（下一波生效）；game.difficulty 读当前
game.combat.raidPlan(3)       // 这一档第 3 波来谁（计划表，不含进场时机）
game.setOrientation('portrait')       // 在桌面窗口里锁定竖屏档位
```

`?seed=20261019` 换一张地图（同一个 seed 永远同一张图，连抽卡序列、小人长相、敌人来点都一样）。
`?difficulty=easy|normal|hard` 直接指定这一局的难度（不给就读本地偏好，再不给就是正常）。

## 画面是怎么回事

- **正交投影**：`OrthographicCamera`，远处建筑不会缩小，格子尺寸全程一致 —— 这是红警/帝国时代那种平铺感的地基。
- **2.5D 俯角**：默认俯角 50°、方位角 45°。看得见屋顶，也看得见立面；`game.camera.setPitch(25)` 会更贴红警。
- **短边锁格子**：相机按"屏幕短边看几格"来定视野，所以横竖屏来回切，建筑不会突然变大变小。
- **一次 draw call 铺完地图**：2116 格分两个 InstancedMesh（陆地 + 水面），树/灌/岩各自合批一个。
  水面和发光晶簇不合批 —— 顶点色走不了 emissive，而晶脉"亮着"本身就是玩法信号。
- 建筑是**程序化建模**：一份"说明书"（`box/prism/plinth/cyl/cone/crystal`）拼出低多边形模型。
  将来换真实 glTF，只动 `src/game/models/`，玩法和 UI 一行不改。
- 界面材质也是**现算的**：木纹与镀金是启动时用周期噪声生成的小图（见下方"界面是块木头"），
  玩家还能自己调，并给一个可分享的 ID。

分层只有一条规矩：**`engine/` 不许 import `game/`，`game/` 不许 import `ui/`。**

## 核心循环

```
抽卡 ──▶ 建筑许可 ──▶ 盖楼 ──▶ 产晶钻 ──┐
   ▲                                  │
   └──── 经济卡（永久 +/s）· 人口卡（上限）◘ 回合结算（财富自动入账）◀┘
```

### 回合：准备 → 接敌 → 结算

- **敌人进攻 = 回合开始，敌人清完（或拖过 90 秒）= 回合结束**，结束时财富一次性自动入账。
- **一波不是一次塞完**：按难度分成几涌，每组几只、组间隔几秒，从一处或几处边缘进来。
  后面还有涌的时候不算"清场"，回合不会在两涌之间提前结算。
- **准备时间（60 秒）内水晶不涨**；金币整回合都在攒，但都压在结算那一刻才进钱包。
- **面包和人口是"容积"，不是每回合增加的产量**：
  战斗中房屋被大量摧毁 → 人口容量当场掉下去，但**本回合兵营照常产兵**（回合没结束、没结算）；
  结算之后容量才生效，玩家必须再抽到民居才补得回来。
  反过来，抽到民居是**立刻**多 4 个人口 —— 快照只往上走，不往下走。

### 三档难度：只动"怎么来敌"，不动攻防血

点顶栏「难度」循环切换（简单→正常→困难），或开局用 `?difficulty=easy|normal|hard`。
**换档下一波才生效** —— 正在打的这波不许中途变节奏，牌上会写成「难度·正常→困难」。
档位也记进存档：接着上一局刷新，还是那一档。

拧的只有两类东西（`config.ts` 的 `DIFFICULTY`，单位表一个数字没动）：

| | 每波几只 | 第 1 波 | 每组几只 / 隔几秒 | 从几处来 | 混兵 | 扑不扑主城 | 急不急 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 简单 | 2 + 0.5×(N-1) | 2 只 | 2 只 / 5 秒 | **3 处**（乱出兵） | 第 8 波起混远程 | 谁近拆谁 | 每打一下停 1.2 秒 |
| 正常 | 4 + 1.2×(N-1) | 4 只 | 4 只 / 4 秒 | 1 处 | 第 3 波远程、第 5 波石怪 | 主城减 2 格 | 不喘 |
| 困难 | 6 + 2×(N-1) | 6 只 | 6 只 / 2 秒 | 2 处 | 第 2 波远程、第 3 波石怪 | 主城减 4 格（宁远也要打心脏） | 不喘，**远程还会转头射你的兵** |

实测（对照台，纯草场、钱管够、同一 seed；读数 = 判负回合，撑过第 20 波记 ≥21）：

| 摆法 | 简单 | 正常 | 困难 |
| --- | --- | --- | --- |
| 1 箭塔 + 田庄 | 9 | 2 | 2 |
| 2 箭塔 + 田庄 | 10 | 3 | 2 |
| 3 箭塔 + 田庄 | 15 | 5 | 3 |
| 2 箭塔 + 炮塔 + 田庄 | 15 | 5 | 4 |
| **2 箭塔 + 兵营 + 田庄** | 10 | **9** | **6** |
| 2 箭塔 + 兵营 + 神龛 + 田庄 | 13 | 9 | 6 |

正常档那一列就是"要动脑筋"的形状：**只堆塔到 5 波，塔 + 兵一步跳到 9 波** ——
火力与人手搭配是有效解，纯堆塔不是。困难档更陡：没兵几乎撑不过 4 波。
简单档则一塔就能舒服过 9 波，用来认路。

### 面包：磨坊 + 田地 + 房屋

```
一栋民居 = 1 个面包 + 4 个人口上限
一座磨坊 = 每回合 1 个面包，四周每贴一块田地再多 1 个
主城     = 每回合白送 2 个面包
```

- **田地只能贴着磨坊盖**（离开磨坊直接判 `no-adjacent`，幽灵是红的）。
- 面包不够时盖不了房屋，提示会**点名缺的是面包**（"盖不了：资源不够（面包 1）"）。
- 面包有容积上限：底子 6，每座磨坊 +6。到顶就不涨，多出来的不是消失，是没进账。

### 人口是岗位，不是闸门

塔楼 1、炮塔与魔法塔各 2、兵营类 4、田地 1、磨坊 2 个人口。
**人口不够时照样能盖**（不然玩家会被卡死在"想补火力但补不了"），代价是那栋楼**缺员**：
塔不开火、兵营不产兵，头顶挂一枚"人口头像 + ✕"的徽章。缺谁按建造顺序排，同 seed 同摆法结果一定。

### 三座塔：伤害、射速、弹夹各不相同

| 塔 | 单发 | 射速 | 弹夹 | 空仓装填 | 射程 | 人口 | 特点 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 箭塔 | 8 | 0.7s | 6 | 2.2s | 5.5 格 | 1 | 最远，一弹夹打完要喘 |
| 炮塔 | 22 | 1.6s | 2 | 5s | 4.5 格 | 2 | 铁弹落地炸 1.4 格，专治成群 |
| 魔法塔 | 3 | 0.22s | 10 | 3s | 6 格 | 2 | 快得看不清，单发很轻 |

- 弹丸是**有实体的**：箭是 2D 像素箭（跟着飞行方向转），炮弹是 3D 黑色方块走抛物线、落地爆炸 + 一把往上飘的像素烟，
  魔弹是青色光点。**伤害在落地那一刻才发生**，不在开火那一刻。
- 点塔 → 头顶弹「升级 Lv? · 金X 水Y」「拆除」；**拆除要再点一次"确定"才动手**。
- 升级**不占抽卡**，只花金币与水晶，最高 Lv3（每级伤害 ×1.35、射程 +0.6、装填 −10%）。魔法塔每一级都贵过另两塔同级。

### 兵营与集合旗

一栋营固定产一支小队（兵营 3 骑士 / 弓手营 4 弓箭手 / 兽穴 3 兽人 / 神龛 2 牧师）。
死一个先从**储备**里立刻补，储备空了才在头顶走生产读条。兵出营后跟着**集合旗**走，营位就是布防点。

旗子那三步是：**点兵营 → 头顶弹旗 → 点旗子收进"旗子袋" → 点旗子袋 → 点一处地面放下**。
全程只用点按（不靠悬停、不靠长按），一次手里只握一面。

### 采矿是算出来的，不是给的

矿井和精炼厂自己不产晶钻，它们**派小人去附近的晶脉跑运输**：

```
每秒趟数 = 脚程速度 ÷ (2 × 到矿的格数)      每秒产出 = 趟数 × 每趟载重
```

- 矿越远，路上耗得越多，产量越低；**超过 7 格直接不派人，产量为 0**。
- 精炼厂的高产不是凭空加成，而是小人走得快（3.2 格/秒 vs 矿井 1.2），还能同时包 3 个矿点。
- 一条晶脉同一时刻只归一栋楼，免得两栋挤一个矿点白送产量。

### 晶脉上盖楼要过一道确认

默认晶脉不是"不许盖"，而是"盖之前问一次"：**在这里建XX会毁掉 N 格晶脉，毁掉之后这块地方再也采不出东西**。

- 点取消 → 一格都不动，许可也不扣。点确定 → 楼起来，那几格永久变成裸土（拆楼也不变回来）。
- 弹窗下方有"不再提示"，勾了就记在本地（`Prefs`，无痕模式自动退回内存存储）。
- 幽灵三种脸色：绿=随便盖，**琥珀=能盖但会毁矿**，红=盖不了。这个判断和落位用的是同一个函数。

### 屏幕上现在看得见什么

战斗内核里的数早就有了，缺的一直是"露出来"。这一轮补上六样：

| 位置 | 内容 | 什么时候出现 |
| --- | --- | --- |
| 楼头顶 | **血条六格**（剩两格以下翻红） | 掉过血才挂；满血不挂，一屏幕条等于没有信息 |
| 楼头顶 | **生产读条** + 一句 `生产中 40%` / `补 2/3 · 储备 1` / `满编 3/3` | 兵没满编时 |
| 楼头顶 | **弹夹**：`Lv2 · 装填 3.4s` / `Lv1 · 弹夹 5/6` | 塔打空或装填中 |
| 楼头顶 | 人口头像 + ✕ | 排不到人手（缺员的塔不开火、兵营不产兵） |
| 来点格上 | `第 3 波 · 从这边来 · 8s`（简单/困难一档多处来敌时写成 `从 3 处来`，标出来的那一处是首要来点） | 准备阶段最后 15 秒 |
| 全屏 | 判负面板：撑过第几回合、还剩几栋楼、场上几只敌人 + 「重开这一局」 | 议事厅被打掉 |

判负那句"还剩几栋楼"**不含议事厅自己**：它是在楼真从账上消失之后才广播的，
早一步统计就会把刚塌的心脏算成"还在"。这条踩过一次，锁在 `tests/readouts.test.ts`。

### 存档落在回合之间

- 盖楼、拆楼、回合结算三个时刻自动写本地；**战场上的兵与弹不存**，
  所以刷新 = 回到上一次结算，正在打的这一波重新来。文案里就这么写，不假装能续战斗。
- 档里带版本号与 seed：**版本不符或 seed 不符就整份丢掉**，不猜、不迁移——
  猜错的存档比没有存档更坏（楼是按格子记的，换张图去盖它们等于凭空造 bug）。
- 读档走 `adopt()`：走盖楼的全部副作用（占地、矿脉计划、事件），但**不扣资源、不扣许可**。
  这条有专门的锁：一个许可都不发的新世界，读档照样把楼摆回来，金币与许可数与源局全等。
- 「重开这一局」先清档再跳同一张图（`?seed=` 带过去），不清的话读档会把已经输掉的那局再端回来。

### 操作

拖 = 平移 ｜ 双指捏合 = 缩放 ｜ 双指转 = 转视角 ｜ 滚轮 = 缩放 ｜
点空地 = 选中那格 ｜ 点楼 = 选中那栋 ｜ **再点同一个目标 = 取消选中** ｜ **长按楼 = 头顶弹气泡说明** ｜
点塔 = 头顶弹升级/拆除 ｜ 点旗子 = 收进袋 ｜ **点顶栏「材质」或按 T = 开调参面板** ｜ Esc = 谁在最上面先收谁。

### 界面是块木头

面板不是渐变糊出来的，是**启动时现算的噪声小图**（`src/ui/theme.ts`）：

- 三层周期值噪声（大弯 → 长横纹 → 细颗粒）+ 每 12 像素一道板缝，亮度**量化成 6 档**；
- 图只有 48×48，按整数倍放大配 `image-rendering: pixelated` ⇒ 放大后看到的是真方块，不是糊；
- 按键走镀金：金色渐变上压一层现算的拉丝纹理，顶边一道镜面高光；面板边框是"外深内浅 + 一条金发丝"的雕刻框。
- 噪声的格点序号**取模**，所以平铺看不见接缝 —— 这条有锁（`tests/theme.test.ts`），
  而且写锁的过程里揪出了实现本身的一个错（y 行混合把 `tx` 写成了 `ty`）。

### 木头可以自己调，还带一个分享码

点顶栏「材质」（或按 `T`）开面板：八条滑杆调**明度 / 色阶档数 / 纹路密度 / 板宽 / 板缝深浅 /
像素块放大 / 木纹变体 / 镀金强度**，另有淡·中·重三档预设与"恢复默认"。

- **改动自动保存**，没有保存按钮；存进本地偏好的**就是那个 ID**，所以不会出现"参数与码对不上"。
- 每次改动同时输出**独有 ID**（如 `mk-11q37sz`）：同一套参数永远同一个码，别人贴回输入框就是同一块木头。
  八个字段量化后 28 bit，base36 六位装得下；前缀里那一位是版本号，**以后加字段必须升版本**。
- 贴回来的码读不出来就**什么都不改**，只提示一句 —— 不让一个错字偷偷换掉玩家的界面。
- 拖动过程中不重算纹理（实测热态重算 4–7ms，冷启动那一次 161ms 含 PNG 编码 warm-up），
  最后一次改动后防抖 220ms 再算，面板底部把耗时显示出来。
  这里故意不做"CSS 滤镜先凑一下"的预览：滤镜下的旧纹理和真纹理不是一套，松手会跳，玩家以为坏了。

| 读数 | 实测 |
| --- | --- |
| 默认长相的码 | `mk-11q37sz`（钉在锁里，偷偷改默认值会红） |
| 热态重算两张纹理 | 4–7ms（木 2 + 金 2） |
| 冷启动第一次生成 | 木 161ms + 金 68ms |
| 500 组随机参数往返 / 2000 组撞号检查 | 全等 / 2000 个互不相同 |

### 小人是拼出来的，不是画的

素材来自 Pixelart Sprite Mixer（来源与授权见 `public/assets/dudes/CREDITS.md`）。它**不是**程序化几何：
全代码零三角函数——一个小人 = 三张贴纸各取一格叠起来，再按"魔术色"整像素换色。

| 事实 | 实测 |
| --- | --- |
| 单帧尺寸 | 16 × 24 像素 |
| 拼装空间 | 333 个头 × 103 张脸 × 5 组调色板各 39 色 |
| 体型 | 本包只有 **1 行**（原版按行分 human 0-15 / animal 16-32 / monster 33-53…） |
| 帧表 | 703 列动画；已量到 21 条动作（近战/弓/法/牧/冲撞/被击飞各有自己的动作） |
| 空列 | 头表 14 个分区的**起始列全是空格子**（0,34,51,63,102,127,150,164,200,210,240,274,306,318）⇒ 取头一律"分区 ∩ 非空列" |
| 蓝带 | suit 调色板 39 色里满足 `B>R+25 且 B>G+15` 的恰好 5 条 ⇒ 自己人从这 5 条里取，敌人随机 |
| 朝向 | **正面素材**（剪影左右对称度 0.917–0.969）⇒ 卡片永远正对相机，不做左右翻面 |
| 可复现 | 上游是 `Math.random` 不可播种 ⇒ 长相改由 `seed + 阵营 + 兵种 + 变体` 派生，取样顺序不影响结果 |

只搬了**算法**（`src/game/dudes/` 全部自己重写，没拷一行上游代码），素材是 4 个原样未改的数据文件。
运输小人站在矿井与晶脉之间来回走，**来回秒数用的就是经济算产量的那条公式**，
所以不会出现"人跑得飞快而产量没变"。上限 48 人，因上限没派出去的任务在左上角显成"排队未派"。

授权两件事分开看：代码我们重写了（上游是 AGPL-3.0）；**素材自身条款仓库里没有**，
对外发布前要确认 itch 页面条款。真要换包，只替换那 4 个文件即可，代码不动。
